# Clasificación de noticias — dataset de repaso

Archivo CSV denominado BBC News Train 3 para un ejercicio de clasificación. Los textos son material de terceros; el repositorio no incluye un clasificador implementado.

## Scope

La procedencia y condiciones de reutilización del dataset deben conservarse y verificarse antes de redistribuirlo; no se atribuye la autoría de datos externos al titular del repositorio.
